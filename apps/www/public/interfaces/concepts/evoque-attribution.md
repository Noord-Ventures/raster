# Range Rover Evoque model

The 3D workspace embeds **2022 Land Rover Range Rover Evoque**, by **tonielpro520**, using Sketchfab's official viewer and Viewer API.

- Model: https://sketchfab.com/3d-models/2022-land-rover-range-rover-evoque-034600db0cc94d64a7f3ccb19c7799fa
- Creator: https://sketchfab.com/tonielpro520

- Public metadata: https://api.sketchfab.com/v3/models/034600db0cc94d64a7f3ccb19c7799fa
- Metadata checked: 5 September 2026
- Published geometry: 204,461 triangles, 114,716 vertices, 21 materials

Vlak changes the viewer background and the body paint material for the clay and graphite appearances. The model geometry, glass, trim, wheels and interior remain the creator's work. Viewer wireframe and camera controls operate on the actual model.

The original source model is not bundled or redistributed in this repository. Sketchfab hosts the model, so the interactive viewer requires a network connection and WebGL. No local or generated approximation is shown if it fails to load.
