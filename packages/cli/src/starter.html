A design system on a modular grid

Raster

What it is

Raster is a workhorse of a design system on a modular grid, used for interfaces. The page is paper. Type is Inter. The module is 204 pixels — 184 for the column, 20 for the gutter. Cells are flush. A line is 1px.

This page is what npx @noorddev/raster-cli init writes. The stylesheet is linked. The classes start with rs-. Change the markup; keep the module.

Usage

If you are making a web thing, the head already has the stylesheet. A control is a class on a native element:

<link rel="stylesheet" href="styles/raster.css" />
<button class="rs-btn-primary">Save</button>
html[data-theme="dark"]

Dark scheme: set data-theme="dark" on the root element. The control in the corner does that.

Free & open source

Raster is free and open source. The code is MIT. Type is Inter, SIL OFL 1.1, designed by Rasmus Andersson.

In use

A settings page, a table of jobs, a form with a hint under the field — that is the work. The grid is visible behind the chrome so you can see where a cell begins. Paper is #FAF8F2. Ink is #1A1A1A. The grays between them are the only in-between.

On a phone the field is one column. At 481 pixels it pairs. At 816 it is four modules wide; at 1224 it is six. Edges step from line to line. A button is 40 tall on the desktop and 44 on the phone. The field label sits on a 16px line so the hairline lands on an integer.

Motion is 0.12 to 0.18 seconds. A state the user caused may ease or confirm. Entry is not a show. Color and opacity name the change. Layout rarely moves.

Notes

How do I keep this page?
This is index.html. Edit it. The classes are in styles/raster.css. Add a component with npx @noorddev/raster-cli add button dialog.
Do I need React?
No. Raster is CSS-first. Plain classes on plain markup. React is optional.
Why Inter?
One grotesque for interfaces. Variable, latin + latin-ext, vendored next to the CSS. SIL OFL 1.1.
Where is the documentation?
getraster.com and raster.noord.dev. The repo is github.com/rennvaldes/raster.
